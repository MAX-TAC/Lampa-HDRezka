No license metadata was returned for Online Mod repository; no code copied.
- Python client: https://github.com/ndenissov/HDRezka (MIT, version 5.2.0 as stated in pyproject.toml and hdrezka/__init__.py). Inspected hdrezka/client.py (b821bc635a6b79683446e6d103ebbf41713c074c), api/http.py, api/search.py, post/page.py, post/inline.py, post/post.py, stream/player.py, post/urls/kind/quality.py. Search and title page use HTML parsing via BeautifulSoup; episodic data and stream resolution use site AJAX methods. The client owns isolated HTTP sessions and caches. Default TLS impersonation and automatic redirects are not adopted. is_authenticated() checks expiry state and does not independently prove a server accepted the credentials. Python source imports typing.override and Self; despite advertised >=3.10, use Python 3.12+ for integration.
- Owner's two browser measurements confirm CORS blocks public pages, not every private endpoint. Online Mod proxy architecture explains its potential browser connectivity; no live execution of Online Mod or upstream services performed.

## Implemented
src/catalog-match.mjs: independent conservative title/original title/year/type ranking; ambiguous or unknown types require manual selection. No copied Online Mod source.
backend/rezka_metadata.py: read-only adapter using documented Python library objects Search, Page, InlineItem. Uses injected httpx client, no impersonation, no redirects, TLS verification on, fixed configured origin, no credentials. Explicit URL encoding because upstream Search interpolates query. Unknown content type remains null (catalog schema integration still required). No server deployment, browser connection, login or stream extraction.
Dependencies not installed or integration-tested in this environment. Proposed dependency hdrezka==5.2.0 must be verified against package registry or a pinned upstream commit before deployment. Tests use fake client objects. Python service hosting, access authorization, actual source reachability, API schema integration, and provider account handling are unresolved. Existing beta unchanged. Provider rules prohibit Lampa; do not use third-party credential proxies or impersonation to evade provider restrictions.
